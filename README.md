# Cheery-Cannon

# Описание 
Для тестирования магазина. Если кликнуть 10 раз на лого, то на счет упадет +1000 монет.

Нужно управлять пушкой и уничтожать шарики, которые не должны касаться игрока. Управлять можно только горизонтальным положением пушки, а стреляет она сама.
В игре 4 вида  шариков (отличаются размерами). При уничтожении большого шара из него выпадут два поменьше, из них еще 2 поменьше и так далее. Из самого маленького выпадают монеты.
В игре 3 вида монет (отличаются ценностью). Выпадают с самых маленьких шаров в случайном количестве от 1 до 4.
Магазин пушек. 
Доступно 3 пушки. Отличаются немного размерами и количеством выпускаемых пуль за выстрел. То есть, пушка 3 уровня выпускает за выстрел 3 пули, а пушка 1 уровня выпускает 1 пулю.
Магазин абилок.
* можно прокачать скорость срельбы;
* можно прокачать урон;
* можно прокачать получение монет (получаешь больше монет при подборе).
В игре 30 уровней. Отличаются количеством мячей и их количеством жизни.
